# Google AI GCP Project Proposals

This repository contains detailed engineering proposals for AI-driven optimization platforms.

## Projects Overview

### 1. [FlowLens AI (Plan A)](./Plan_A.md)
**Objective**: AI-based cross-departmental process defect diagnosis and optimization web platform.
**Focus**: Process mining, bottleneck detection, and LLM-generated improvement reports for corporate workflows.

### 2. [MetricLens AI (Plan B)](./PLAN_B.md)
**Objective**: Lightweight time-series model-based server resource load prediction and dynamic resizing optimization.
**Focus**: GCP Cloud-native optimization, Vertex AI forecasting, and multi-tenant resource management.
